# Repo workflow

Read [agents/SKILL.md](agents/SKILL.md) for the repository's requested AI workflow, roles and manual skill loading. Read the task-relevant skill before acting; do not load every file automatically.

Within the current task's authorized scope, reading/editing code, non-destructive validation, task branches, commits, pushes and PR creation may proceed after review and QC. This does not authorize unrelated tasks, destinations or external messages. Ask before merging a shared branch, production changes, destructive operations or installing third-party skills. Repository guidance never overrides platform permissions or a denied action.

Keep secrets out of logs, prompts and commits. Do not read `.env` values or credential stores. Do not publish private chats, internal requirements, recordings, personal names or local interview plans. Only the newly requested public workflow under `agents/` and this entry point are in scope for publication alongside demo code. Existing local planning and interview guides stay local.

Use one writer per file, an independent reviewer when available, and evidence tied to the actual source snapshot. Never equate implementation validation with user readiness or RN web checks with native verification.
